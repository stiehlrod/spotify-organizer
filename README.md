# Spotify Organizer

Personal scripts for organizing a Spotify library: mood/genre playlists, decade
playlists, year-range mixes, fresh rotations, and a high-BPM playlist builder.

## Scripts

| Script | Purpose |
|--------|---------|
| `bot.py` | Fresh rotation playlists (non-repeating) |
| `decades.py` | Playlists grouped by release decade |
| `year_playlist.py` | Playlist of a year range, filled to a target length |
| `bpm_playlist.py` | High-BPM playlist (tempo data from GetSongBPM) |

## Tempo data attribution

Tempo (BPM) data is provided by <a href="https://getsongbpm.com">GetSongBPM</a>
(https://getsongbpm.com), used under their free API terms.
